# cards-icon-feature

Custom **cards** block. Purpose: Strip of icon + title + short text service boxes on light grey (#ececec), 3 across on desktop.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per box; cell 1 = icon image, cell 2 = bold title or heading followed by a description paragraph; a single link in cell 2 makes the whole box clickable.
