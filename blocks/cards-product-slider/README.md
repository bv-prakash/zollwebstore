# cards-product-slider

Custom **cards** block. Purpose: Horizontal slider of authored product cards with prev/next arrows, 4 visible on desktop, 3 on tablet, 2 on mobile.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per product; cell 1 = product image, cell 2 = product name linked to the product page, optional "Item Number: <sku>" paragraph, optional price paragraph.

## Supported variations

No variations.
