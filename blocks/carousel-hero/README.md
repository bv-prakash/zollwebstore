# carousel-hero

Custom **carousel** block. Purpose: Full-width rotating hero banner of linked, image-only slides with dot navigation.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per slide; cell 1 = slide image linked to its target (link may wrap the image or sit next to it), cell 2 = optional overlay text (usually empty, text is baked into the image).

## Supported variations

No variations.
